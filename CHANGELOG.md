# Changelog

## 1.0.0 — 2026-11-20

- One calendar or two calendars in a shared grid.
- Gregorian and Umm al-Qura Hijri calendars.
- Separate languages, digits, week numbers and year progress for each calendar.
- Time and date formats for horizontal and vertical bars.
- Invalid selections keep the last valid calendar selection.
- Safe live switching between one and two calendars.
- Multiline bar labels fit Arabic and Latin fonts without cutting off the second line.
- Explicit popup and delegate types, with a release check that rejects QML warnings.
- Built on Omarchy's original clock, with offline tests and Qt format checks.
